1. Physical Refraction Architecture

        
The liquid glass illusion operates on a procedural 2D canvas normal-map generator coupled with an SVG <feDisplacementMap> and CSS backdrop-filter:

        
function roundedRectSDF(t, s, n, r, a) {
  let i = Math.abs(t) - n + a, o = Math.abs(s) - r + a;
  return Math.min(Math.max(i, o), 0) + length(Math.max(i, 0), Math.max(o, 0)) - a;
}

        
        
2. Tangent Normal Vector Encoding

        
Deflections are mapped into 8-bit RGB channels: R = horizontal displacement ($dx$), G = vertical displacement ($dy$), B = 255 (neutral surface normal), Alpha = 255. The normal map is serialized as base64 and fed into <feImage>.
